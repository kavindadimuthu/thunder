# `ThunderIDPlugin`

The `ThunderIDPlugin` is a Vue plugin that initializes the <ProductName /> SDK in your Vue 3 application. It globally registers the `<ThunderIDProvider />` component (so you can use it without importing) and injects the SDK's base styles into the DOM.

## Overview

Install the plugin once during app bootstrap. After installation you can use `<ThunderIDProvider />` anywhere in your templates without explicit imports, and all built-in components will render with the SDK's default styles.

## Usage

The plugin should be installed when the Vue app is created, before mounting.

### Basic Usage

A minimal setup registers the plugin in `main.js`/`main.ts` and wraps the app with `<ThunderIDProvider />` in your root component.

**Step 1:** Register the plugin in `src/main.js`:

```js title="src/main.js" showLineNumbers
import { createApp } from 'vue'
import { ThunderIDPlugin } from '@thunderid/vue'
import App from './App.vue'
import './style.css'

const app = createApp(App)
app.use(ThunderIDPlugin)
app.mount('#app')
```

**Step 2:** Wrap your application with `<ThunderIDProvider />` in `src/App.vue`:

```vue title="src/App.vue" showLineNumbers
<template>
  <ThunderIDProvider
    client-id="<your-app-client-id>"
    base-url="https://localhost:8090"
  >
    <!-- your app content goes here -->
  </ThunderIDProvider>
</template>
```

### Delegated Mode

When running inside a host framework that provides its own injection context (for example `@thunderid/nuxt`), install the plugin in `'delegated'` mode. In this mode the plugin skips browser-only initialization and does not register `<ThunderIDProvider />`, so it can be used safely during SSR.

```ts title="src/main.ts" showLineNumbers
import { createApp } from 'vue'
import { ThunderIDPlugin } from '@thunderid/vue'
import App from './App.vue'

const app = createApp(App)
app.use(ThunderIDPlugin, { mode: 'delegated' })
app.mount('#app')
```

## Options

The `ThunderIDPlugin` accepts the following options:

| Option | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `mode` | `'browser' \| 'delegated'` | ❌ | Installation mode. `'browser'` (default) runs the full browser PKCE flow and registers `<ThunderIDProvider />` globally. `'delegated'` is used when the host framework provides all injection context via `app.provide()`. |
