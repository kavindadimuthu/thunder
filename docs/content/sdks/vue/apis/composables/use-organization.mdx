# `useOrganization()`

The `useOrganization` composable provides access to the current organization, the list of organizations the signed-in user belongs to, and operations to switch or create organizations. It is the recommended way to build custom B2B/organization UIs.

## Usage

Import and use the composable inside `<script setup>` (or `setup()`) to access organization data:

```vue title="src/OrgSwitcher.vue" showLineNumbers
<script setup>
import { useOrganization } from '@thunderid/vue'

const { myOrganizations, currentOrganization, switchOrganization } = useOrganization()

async function handleSwitch(org) {
  await switchOrganization(org)
}
</script>

<template>
  <div>
    <p>Current: {{ currentOrganization?.name }}</p>
    <ul>
      <li v-for="org in myOrganizations" :key="org.id">
        <button @click="handleSwitch(org)">{{ org.name }}</button>
      </li>
    </ul>
  </div>
</template>
```

:::note
This composable must be used inside a component rendered within `<ThunderIDProvider />`. Otherwise, it will throw an error.
:::

## Return Values

| Property | Type | Description |
| :--- | :--- | :--- |
| `currentOrganization` | `Ref<Organization \| null>` | The organization the user is currently operating in |
| `myOrganizations` | `Ref<Organization[]>` | The list of organizations the signed-in user is a member of |
| `isLoading` | `Ref<boolean>` | `true` while an organization operation is in flight |
| `error` | `Ref<string \| null>` | Last error message from an organization operation, if any |
| `switchOrganization` | `(org: Organization) => Promise<void>` | Switches to the given organization (performs token exchange) |
| `createOrganization` | `(payload: CreateOrganizationPayload, sessionId: string) => Promise<Organization>` | Creates a new sub-organization (when available) |
| `getAllOrganizations` | `() => Promise<AllOrganizationsApiResponse>` | Fetches the paginated list of all organizations |
| `revalidateMyOrganizations` | `() => Promise<Organization[]>` | Re-fetches the user's organization list from the server |

## Error Handling

If `useOrganization` is called outside of a `<ThunderIDProvider />`, it throws:

```text
[ThunderID] useOrganization() was called outside of <ThunderIDProvider>. Make sure to install the ThunderIDPlugin or wrap your app with <ThunderIDProvider>.
```
